# Portfolio Express — Roger Medina

Sitio web personal moderno, limpio y responsive desarrollado con HTML5, CSS3 y JavaScript vanilla.

## Características

- **Hero principal**: Nombre "Roger Medina", subtítulo "Desarrollador web FULL-STACK y creador de proyectos digitales" y botón de llamada a la acción "Ver proyectos".
- **Sobre mí**: Resumen profesional, propuesta de valor y métricas destacadas.
- **Habilidades**: Tarjetas con bordes redondeados y diseño limpio para:
  - Inteligencia Artificial
  - Automatizaciones
  - Creación de apps
  - Formación online
- **Proyectos**: 3 tarjetas de muestra con mockups ilustrativos, tags de tecnologías y detalles.
- **Contacto**: Sección con formulario interactivo y botón principal "Contactar".
- **Diseño**: Fondo claro, tipografía moderna (`Plus Jakarta Sans`), paleta profesional, microinteracciones suaves y completamente responsive para dispositivos móviles y escritorio.

## Estructura de archivos

- `index.html`: Estructura semántica completa de la landing page.
- `styles.css`: Estilos visuales modernos, diseño de tarjetas, tipografía y media queries responsive.
- `script.js`: Menú responsive móvil, scroll interactivo y feedback del formulario de contacto.

## Cómo abrirlo

Puedes abrir el archivo `index.html` directamente en cualquier navegador web o servirlo mediante extensiones como Live Server.
